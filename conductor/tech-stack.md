# Technology Stack

## Core Tools
- **Configuration Management:** [Dotter](https://github.com/SuperCuber/dotter) - A dotfile manager and templater written in Rust.
- **Version Control:** [Git](https://git-scm.com/) and [Jujutsu (jj)](https://github.com/martinvonz/jj) - Modern version control systems for managing configuration history.
- **Shell:** [Fish Shell](https://fishshell.com/) - A smart and user-friendly command line shell.
- **Prompt:** [Starship](https://starship.rs/) - The minimal, blazing-fast, and infinitely customizable prompt for any shell.

## Terminal & Workflow
- **Terminal Emulator:** [WezTerm](https://wezterm.org/) - A GPU-accelerated cross-platform terminal emulator and multiplexer.
- **Multiplexer:** [Zellij](https://zellij.dev/) - A terminal workspace with batteries included.
- **CLI Utilities:**
    - `eza`: A modern replacement for `ls`.
    - `bat`: A `cat` clone with wings (syntax highlighting).
    - `ripgrep` (rg): A line-oriented search tool.
    - `fd`: A simple, fast and user-friendly alternative to `find`.
    - `fzf`: A command-line fuzzy finder.

## Automation & Scripting
- **Windows Automation:** [AutoHotKey (v2.0)](https://www.autohotkey.com/) - A powerful scripting language for Windows desktop automation.
- **Deployment Scripts:** Bash and POSIX-compliant shell scripts for bootstrapping and environment-specific logic.
